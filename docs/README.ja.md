## 概観——Lucent という選択

世に溢れるメモアプリの大半は、「美しさ」「プライバシー」「賢さ」の三つから二つだけ選べという不文律を課してきます。ふたつを選び、残るひとつに嘆息する——それが暗黙の作法でした。Lucent はその取り決めを静かに辞退します。あなたが綴るすべては暗号化データベースに封じられ、デバイスの外へ一歩も踏み出しません。アシスタントは、費用を払って使うクラウドモデルにも、手もとのマシンで動くローカルモデルにも、あるいは一切の不在にも設定できます。そしてビルドにローカルの開発環境は一切不要——GitHub でボタンをひとつ押し、珈琲を淹れに席を立ち、戻ってくる頃には APK か Windows インストーラーが仕上がっています。

## ひとつのアプリ、あらゆる場所へ

Lucent は **ひとつの製品にひとつの共有された心臓** を宿しています。基本原則は明快です——「出荷するすべてのプラットフォームに、すべての機能を届ける」。あなたの掌と机の上は、同じ言葉で語りかけます。

- **`:app`** — Android アプリケーション（Kotlin + Jetpack Compose、Room on SQLCipher、llama.cpp を NDK 経由で）。`.github/workflows/build.yml` が署名済みリリース APK をビルドします。
- **`:desktop`** — デスクトップアプリケーション（現時点では Windows。Compose for Desktop、純正 JVM、JDBC 経由の SQLite、llama.cpp は DLL としてコンパイル）。`.github/workflows/build-windows.yml` がダブルクリックで動く `.exe` インストーラーをビルドします。
- **`:shared`** — 両プラットフォームがコンパイルする単一のソースツリー。ビジネスロジック、データ、ほとんどの UI、四ヶ国語対応の翻訳カタログがここに集約されています。一度の編集が、ふたつの世界を同時に塗り替えます。

共有できるものはすべて `shared/` に住まいます。`SettingsRepository`、`Daos`/`Db`、`DocumentExport`、そして大画面対応など、共有し得ない少数の要素だけがプラットフォームごとに分かれて存在します——それらの継ぎ目が深いからです。ネイティブビルドの各段階はそれぞれ任意なので、どこかで躓いても、ただの待合室ではなく動くアプリが手に入ります。

## 意見を述べるだけではない、行動するアシスタント

ここにこそ Lucent を定義する核心があります。お好みのモデルを持ち込んでください——OpenAI、Anthropic、Google のリクエスト形式を流暢に解し、複数のプロファイルを保存してワンタップで切り替えられます——あるいは、すべてをデバイス上で完結させることもできます。何も設定しなければアシスタントは姿を現さず、メモアプリとしては何ひとつ欠けるところがありません。

このアシスタントの真価は、**実際に手を動かせる** ことにあります。メモの作成、読み取り、編集、色づけ、ピン留め、アーカイブ、削除。タスクの作成、完了、再開、スケジュール、優先順位づけ。本格的なフィルター言語による検索。ファイルの添付、リネーム、削除。何かを変更する前に、アシスタントは自らの意図を正確に提示します——あなたの言語で、それ自体が編集画面となるダイアログの中で、一バイトも書き込まれる前にすべてのフィールドを吟味できます。最終決定は、常にあなたの手の中にあります。意見だけあって手のない相手とは、おしゃべりで終わるでしょう。けれどもこれは、必ず扉を叩き、招かれてから入る執事なのです。

会話はいくらでも続けられ、あなたとともに旅をします。モデルの推論過程は折りたたみ可能なトレースとして、ツール呼び出しごとに一行ずつ静かに開示されます。

## 過去の自分を記憶するメモ

意味のある編集はすべてスナップショットされます。かつてメモに何と書かれていたかを正確に読み返すことができ、自信に満ちた書き直しがただの楽観に過ぎなかったと気づいたときには、いつでも復元できます。`[[買い物リスト]]` と入力すれば、それはタップ可能なリンクに変わります。まだ存在しないタイトルを指していればリンクは赤く灯り——タップするとそのメモが静かに生成されます。Markdown は見たいときにレンダリングされ、そうでないときは入力されたままの姿を保ちます。チェックリストは第一級市民です。その場で項目を言い換えることも、簡素な一行が野心的な段落に育ったときには広々としたポップアウトエディターを開くこともできます。タグ、色、ピン留め、個別に暗号化された添付ファイル、リッチテキスト、言葉の及ばない想念のための doodle キャンバス、そして独自のロックを持つプライベートエリア——ごみ箱の傍らには下書きも控えており、未完の思考が打ち棄てられることはありません。

白紙のメモは、ジャーナル、ミーティング、プロジェクト案、チェックリストという四つのワンタップスターターを差し出します。そして真の妙技は、自分だけのテンプレートにあります。テンプレートを保存すれば、次に白紙のページを開くたびにそれが出迎えてくれます。長押しでテンプレート——組み込みのものも含めて——を編集したり、役目を終えたものを退かせたりできます。

## 実のある期限を持つタスク

サブタスク、優先順位、繰り返しスケジュール、そして再起動後も失われないリマインダー。期限は自然言語から読み解かれます——*来週の金曜日の6時に* は確かなタイムスタンプと確かなアラームになります。繰り返し周期は第一級の機能であり、いつか破綻する苦肉の策ではありません。タスクを完了すると、そのチェックリスト全体も連れ立ってチェックされ、済んだタスクは専用の画面へと静かに退場します。

## すべてをデバイスの上で

`.gguf` ファイル（またはそれを含む `.zip`）をインポートすれば、アシスタントはデバイス上で直接動作する llama.cpp を用いて応答します——アカウントも API キーもネットワークも不要で、アプリを離れた瞬間にモデルはアンロードされます。スマートフォンではおおむね 1〜4 GB の Q4 モデルが心地よい均衡点です。デスクトップならもう少し贅沢を許せるでしょう。ツールはローカルではオプトイン制で、GPU アクセラレーションはあらかじめ警告を示した上で選択できます。CPU は常に動作し、GPU が合わなければ優雅にフォールバックします。ビジョンもまた選択肢のひとつです——mmproj ファイルをインポートすれば、アシスタントは写真を見て、少しだけ千里眼を授かった司書のように語ってくれます。

## 四つの言語、儀式なき切り替え

英語、中文、日本語、한국어——すべての画面、ダイアログ、日付書式、テンプレート。言語を切り替えれば、アプリ全体が同じフレームの中で寄り添うように追従します。ひとつのカタログがあり、インターフェースはそこから読み取るだけ——各語句は、注意深さではなく設計によって、ただ一度だけ保持されています。

## 意匠——恥じることなく、硝子のように

生きたグラデーションが曇りガラスのパネルの奥をゆるやかに漂い、その下を過ぎるものを柔らかくぼかしながら、決して同じ模様を繰り返さず、デバイスがあらかじめ承諾した負荷の中で息をしています。八つのスタイルファミリーにわたる豊かなパレット。自動巡回あるいはランダムに選ばれたコンパニオンが、ゆったりとパレットを巡ります。ライト、ダーク、システム、そして Monet 調のテーマのギャラリー——Android 12 以降では、パレットがあなたの壁紙からその日の彩りを借り受けます。ウィジェットは同じ硝子質の表面をランチャーにも届けます。Windows では、アプリはトレイに収まり、サイドバーが下部タブバーに代わります——広いモニターには、引き伸ばされたスマートフォンの衣装よりふさわしい仕立てがあるからです。

## 堅牢な錠前と、あなたと共に旅するバックアップ

アプリロックは丁寧なお願いではなく、実直なブルートフォース対策です。エスカレーションするクールダウン、再起動を越えて持続するカウンター、任意のセキュリティ質問、任意の自己破壊機能、そしてクールダウン中は穏やかに「不在」となる指紋認証（Android）または Windows Hello（Windows）。データベースは保存時に暗号化され、添付ファイルは個別に暗号化され、バックアップは単一のパスワード保護可能な `.lcb` ファイルとして、メモ、タスク、履歴、チャット、添付ファイル、設定をデバイス間で携えます——一項目も変更される前にプレビューが行われ、自動実行の設定も可能です。誰にも読めないバックアップは、思い出の品であってバックアップではありません。だからこそ、出ていくときにも入ってくるときにも、このバックアップは読まれるのです。

## 約束ではなく、構造としてのプライバシー

あなたがエクスポートするか、モデルに見せる理由を与えるまでは、何ひとつデバイスの外へは出ません。共有シートの統合はデフォルトで無効。診断情報もデフォルトで無効、ローカルにのみ保存されます。接続するアシスタントサービスはすべてあなた自身の選択です。クラウドミラーリングはあなた自身が WebDAV 経由で設定するモジュールです。暗号化における唯一の意図的な例外——Markdown、Word、PDF、Excel へのエクスポート——は、どこでも開けるファイルであり、それこそがそもそもの目的です。

## Rust、ただし真に必要な場所だけ

ふたつのホットパスが Rust で書かれ、JNI 経由で呼ばれています——バックアップと添付ファイル暗号化を支える PBKDF2 および AES-256-GCM のルーチンと、漂う背景の数学的処理です。いずれも、ネイティブライブラリが存在しない場合は同一の Kotlin へ静かにフォールバックするため、アプリがコンパイラに人質として取られることは決してありません。

## ビルド方法——そう、パジャマ姿でスマートフォンからでも

Android Studio も、ローカル SDK も、コマンドラインも不要です。GitHub にプッシュし、**Actions** を開き、望みのワークフローを実行し、成果物をダウンロードするだけ——適切に署名されたリリースか、ダブルクリックで動くインストーラーが手に入ります。ワークフローはリポジトリの中に収められ、レシピは作者の記憶の中ではなく箱の中にあり、ビルドはコードと同じだけの透明性で検証可能です。

## プロジェクト構成

```
shared/       ただひとつの共有ソースツリー — ビジネスロジックとほとんどの UI がここに
              ONCE 存在し、:app と :desktop の両方がコンパイルします。ここにあるファイルを
              編集すれば、両方のプラットフォームが同時に変わります。
app/          Android モジュール (:app) — Activity シェル、Room データベース層、JNI ブリッジ、
              ウィジェット、その他 Android 固有のコードのみ
desktop/      デスクトップモジュール (:desktop) — Compose for Desktop シェル、android.* の
              JVM シム、JDBC データベースコア、エンジン DLL 用ネイティブ CMake ビルド
rust/         Rust アクセラレーター（全プラットフォーム共通）
.github/      build.yml（Android APK）、build-windows.yml（Windows インストーラー）、check.yml
```

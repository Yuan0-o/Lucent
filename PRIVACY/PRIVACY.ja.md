# Lucent プライバシーポリシー

Lucent は Android と Windows 向けのノートおよびタスク管理アプリです。本ポリシーでは、このアプリが端末内に何を保存し、何を端末の外へ送るのか、そしてその両方をあなたがどう制御できるのかを説明します。ここに書かれているのは、このリポジトリでビルドされる Lucent そのものです。

**最終更新：2026年9月25日**

## 1. 概要

- Lucent にはアカウントも登録もなく、開発者が運営するサーバーもありません。あなたのノート、タスク、ファイル、利用状況を開発者が受け取る手段は存在しません。
- ノート、タスク、ノートブック、チェックリスト、バージョン履歴、アシスタントとの会話、添付ファイル、API キー、各種設定は端末内に保存され、保存時に暗号化されます。
- アプリには解析、広告、テレメトリは一切含まれていません。
- ネットワークを使う機能はすべて任意で、既定ではオフです。クラウドアシスタント、ウェブ検索、セマンティック検索、クラウドバックアップ、自動更新確認が該当します。
- クラウドアシスタントを使う場合、メッセージはあなたが入力した API キーの提供元へ端末から直接送信されます。Lucent を経由することはありません。
- 任意のオンデバイスモデルは完全に端末上で応答し、どこにも何も送信しません。

以下では、これらの記述を境界も含めて詳しく説明します。

## 3. Lucent が端末内に保存するもの

Lucent で作成したものはすべて、端末上のアプリ専用のプライベート領域に保存されます。この領域は他の通常のアプリからは読み取れず、アンインストールまたはアプリデータの消去によって削除されます。

保存される内容は次のとおりです。

- ノート（本文、書式、タグ、色、ピン留めとアーカイブの状態、チェックリスト、落書き、リンク、バージョン履歴を含む）
- タスク（サブタスク、優先度、期限、繰り返し、リマインダー、メモ、バージョン履歴を含む）
- ノートブックとそこに収めた項目
- アシスタントとの会話とメッセージ（モデルが返した思考の記録を含む）
- ノートやタスクに追加した添付ファイル、およびアシスタントに送った添付ファイル
- 読み込んだフォントとローカルモデルのファイル
- 設定（選択したプロバイダー、Base URL、モデル名、API キー、バックアップのパスワード、アプリロックの資格情報、クラウドバックアップの資格情報を含む）
- 診断ログ（診断ログをオンにしている場合）

### 3.1 保存時の暗号化

データベースは SQLCipher で暗号化されます。Android では Room と SQLCipher の組み合わせ、Windows では同梱の JDBC ドライバーを SQLCipher の暗号方式と同じ種類の 256 ビット鍵で構成して SQLite を利用します。ノート、タスク、会話、履歴、設定はすべてこのデータベースの中にあります。

添付ファイルは個別に暗号化されます。各ファイルはディスクに書かれる前に、認証付きの AES-256-GCM コンテナへ 64 KiB 単位で格納されます。ディスク上のファイル名はランダムな識別子であり、アプリ内で表示される名前ではありません。

バックアップも常に暗号化されます。第 6 節をご覧ください。

### 3.2 鍵と機密情報

データベースの鍵と添付ファイルの鍵は、端末上で生成されるランダムな 256 ビット値です。あなたが入力したものから導出されることはなく、平文でディスクに書かれることもありません。Android では Android Keystore が保持する鍵で包んで保護され、端末が対応していればハードウェアによって保護されます。Keystore が利用できない場合は端末内の代替手段に切り替わります。Keystore の不具合でデータが失われないよう、各鍵の復旧用コピーも保持されます。

API キー、WebDAV のパスワード、バックアップのパスワード、アプリロックの資格情報も同じ暗号化された経路で保存され、平文ではありません。アプリロックのパスワードと秘密の質問の答えはそもそも保存されません。保存されるのはソルト付きハッシュだけで、そこからパスワード自体を復元することはできません。

### 3.3 暗号化ができることとできないこと

ここでの暗号化が守るのは保存データです。端末の外へ持ち出されたデータベース、添付ファイル、バックアップは、鍵がなければ読めません。一方で、端末のロックを解除した状態であなたの OS アカウントを使って操作する相手からは守れません。また、アプリを開いている間のデータも守れません。表示や編集中は、復号された内容が必然的に端末のメモリ上に存在するためです。

Lucent はこの点をごまかしません。暗号化ライブラリを読み込めない場合や、データベースを暗号化できない、復号できない場合は、成功したふりをせず事実を記録して報告します。設定には、保存された値が確かに封印され正しく開けることを確認する暗号化チェックがあります。保存されている鍵でデータベースを復号できない場合、Lucent はそれを削除せず脇に退避し、その旨を伝えます。バックアップから復元できるようにするためです。

Android のホーム画面ウィジェットは、ランチャー上にノートやタスクのタイトルを表示します。ウィジェットに表示された内容は、その画面を見られる人なら誰でも見られます。ウィジェットは任意で、いつでも削除できます。

## 4. 端末の外へ決して出ないもの

既定では、何も出ません。ノート、タスク、リマインダー、履歴、添付ファイル、ローカル検索、オンデバイスアシスタントはネットワーク接続を必要としません。

具体的には、Lucent には解析 SDK、広告 SDK、クラッシュレポートサービス、追跡識別子が含まれていません。アカウントの仕組みも、どこかへ送信される端末フィンガープリントもありません。クラッシュシールドをオンにした場合、捕捉したエラーは端末上のローカルログファイルに書き込まれるだけで、送信されません。診断ログも同じです。既定ではオフで、ローカルに書き込むだけで、あなた自身がエクスポートして共有を選んだときにしか外へ出ません。

Lucent にサーバーがないため、開発者があなたのデータを読む方法も、復元してあげる方法もありません。

## 5. データが端末の外へ出る場合

以下はすべて任意で、既定ではオフであり、あなたが制御できます。いずれかを有効にした場合、データはアプリからあなたが設定した第三者へ直接送信されます。Lucent のサービスは存在しないため、そこを経由することはありません。

### 5.1 クラウドアシスタント（API キーを持ち込む方式）

クラウドモードのアシスタントは、あなたが用意した API キーと、あなたが選んだプロバイダーを使います。Lucent は OpenAI 互換、Anthropic 互換、Google 互換のリクエスト形式に対応しており、OpenAI 互換のアドレスであれば DeepSeek や自前のゲートウェイも含めて利用できます。複数のプロバイダー設定を保存し、切り替えられます。

メッセージを送信すると、Lucent は設定された Base URL へ端末から HTTPS リクエストを送ります。その内容は次のとおりです。

- あなたのメッセージ本文
- 現在のメモリ設定に含まれる過去の会話
- アシスタントの動作を定めるシステム指示
- メッセージに添付したファイル
- 応答に必要なノート、タスク、ノートブック、検索の文脈、およびアシスタントが呼び出したツールの結果

API キーは、そのリクエストの認証ヘッダーとしてそのプロバイダーへ送られ、それ以外のどこへも送られません。受け取ったテキストをプロバイダーがどう扱うかは、そのプロバイダーのプライバシーポリシーをご確認ください。それはあなたとプロバイダーの間の取り決めであり、Lucent からは見えず、制御もできません。

アシスタントがあなたのデータを黙って書き換えることはありません。何かを書き込む前に行おうとしている内容を提示し、この確認手順は既定でオンです。ツールは任意です。ローカルモデルには専用のツールスイッチがあり、クラウドアシスタントのツール利用も設定でオフにできます。どちらかをオフにすると、モデルは会話はできても、ノートやタスクを読み書きすることはできません。

### 5.2 ウェブ検索

ウェブ検索は既定でオフです。これをオンにし、アシスタントが必要と判断した場合、Lucent は検索クエリを公開の検索エンジンへ送ります。エンジンはあなたが選ぶか、「自動」のままにします。自動は結果が返るまで順に試します。Bing、DuckDuckGo、Google、Brave、Mojeek、Yandex、Baidu、Sogou、360 検索、そして Wikipedia の検索 API です。検索用の API キーは使わず、アカウントも作りません。クエリのテキストは端末の外へ出て、結果はアシスタントに渡され回答に含まれます。結果を返したエンジンにはクエリとあなたの IP アドレスが見えます。ウェブ検索にはエージェントモードが必要で、ローカルモデルではツールのスイッチも必要です。ブラックアウトモードはこれを完全に遮断します。

### 5.3 セマンティック検索

Lucent のセマンティック検索は、使っているアシスタントにそのまま従うので、別途選ぶものはありません。ローカルモデルを使っている間、索引付けは端末内に留まりますが現在のビルドでは実装されておらず、何も外へ出ません。クラウドモデルを使っている間は、各ベクトルを生成するため、索引付けするテキストが設定済みの AI プロバイダーの embeddings エンドポイントへ送られ、ノートのテキストが端末の外へ出ます。モデルを切り替えれば、この動作もいっしょに切り替わります。

### 5.4 クラウドバックアップ

クラウドバックアップは既定でオフです。オンにすると、あなたがすでにアカウントを持っている WebDAV 互換サービス（Nutstore、Nextcloud、Koofr、その他の WebDAV サーバーなど）のアドレス、ユーザー名、パスワードを入力します。Lucent は `.lcb` バックアップファイルを、指定したサーバー上のフォルダーへアップロードし、復元のために一覧表示とダウンロードも行います。ファイルはアップロード前に暗号化されています。サービスが保存するのは暗号化されたファイルで、入力した資格情報は認証のためにそのサービスへ送られます。自動アップロードは別のスイッチで、こちらも既定ではオフです。

### 5.5 更新の確認

自動更新確認は既定でオフです。これをオンにしたとき、またはあなたが確認を求めたときに、アプリはこのリポジトリの公開 GitHub releases API へ最新リリースの情報を要求し、バージョン番号を比較します。このリクエストに含まれるのは、HTTPS リクエストが一般に運ぶもの（IP アドレスや Lucent を示す User-Agent など）だけで、個人データは含まれません。新しいリリースがあれば Lucent が提示し、あなたが更新を選んだときにだけ GitHub から APK またはインストーラーをダウンロードします。

### 5.6 共有とエクスポート

Lucent がひとりでに外部へ送ることはありません。データを他のアプリへ渡す機能は二つあり、どちらもあなたが制御します。

- **エクスポート。** ノートやタスクを Markdown、Word、PDF、Excel へ書き出す場合や、バックアップを書き出す場合は、保存先をあなたが選んだファイルが作られます。エクスポートした文書は意図的に暗号化されません。エクスポートの目的は別の場所で読めることだからです。そのファイルを入手した人は誰でも内容を読めます。適切だと思う場所に保管してください。
- **共有シート連携。** Lucent を共有先にする機能は既定でオフです。オンにすると、Lucent が他のアプリの共有シートに現れ、テキストやファイルを送り込めるようになり、システムの共有シートにも共有先として現れます。送り込まれた内容は、ほかのすべてと同じ暗号化されたデータベースに保存されます。Lucent が自分から何かを送信することは変わりません。

### 5.7 オンデバイスモデル

GGUF モデルを読み込むと、アシスタントは llama.cpp を使って端末上で直接それを実行できます。このモードではどこにも何も送信されません。返答の生成にアカウントも API キーもネットワーク要求も関与しません。モデルファイルは端末内に残り、アプリを離れるとモデルはアンロードされます。ローカルツールは別のスイッチで、既定ではオフです。GPU アクセラレーションは任意で、オフにできます。

### 5.8 道具箱

メモとタスクだけでなく、assistant には本物の道具箱を持たせられます。読み書きできるワークスペース
フォルダー、シェルコマンド、文書処理、プラグイン、外部サービスへの接続です。いずれも「設定 →
詳細設定 → 道具箱」で個別に切り替えられ、端末の外に出るものは、あなたが有効にし、既定では先に
確認してからでないと動きません。

- **ワークスペース。** フォルダーはあなたが一つ選びます。assistant が読み書きするものはすべて
  その中にあります。「ワークスペース外」を許可しない限り外のファイルは読み取れず、外に書き込む
  ことは決してできません。
- **コマンド。** シェルコマンドの実行は既定で確認を求めます。実行はこの端末上、作業ディレクトリは
  ワークスペース内、制限時間はあなたの設定どおりで、すべて操作ログに記録されます。
- **文書。** Word・Excel・PowerPoint は Lucent 自身のコードが端末上で作成・読み取りします。変換や
  生成のために外部へ送信することは一切ありません。
- **プラグイン。** 任意のツール（Linux 環境、文書ライブラリ入り Python、LibreOffice、Node.js、
  メディア／OCR ツール）は、あなたが求めたときだけ、公式配布元または公共ミラーからあなたの保存
  領域へ直接ダウンロードされます。Lucent はテレメトリーを送りません。
- **接続。** GitHub、Notion、Slack、Google Drive、OneDrive、GitLab、Jira、Linear、WebDAV、および
  追加した MCP サーバーへは、あなたが渡したトークンで端末から直接接続します。送られるのは依頼した
  リクエストだけで、行き先はあなたが設定したサービスです。間に Lucent のサーバーはなく、トークンは
  端末上で暗号化して保存されます。
- **トークンと特権シェル。** GitHub のアクセストークンは暗号化して保存され、保存後は再表示されません。最大5件まで保持できます。Android で assistant に Shizuku 権限を与えるかどうかは独立したスイッチで、既定はオフです。オンにしたときだけ、コマンドがその権限で実行され得ます。
- **サブエージェントのレポート。** 手動で保存したレポートは Markdown ファイルとしてワークスペースの sub-agents フォルダーに書き込まれ、端末の外へは出ません。
- **端末操作（Android）。** 有効にし、アクセシビリティサービスをオンにすると、画面の読み取り、
  タップ、入力、スクリーンショット、アプリ一覧と起動、通知の読み取り、クリップボードとセンサーの
  利用ができます。画面の読み取りは端末内で行われ、それを含むツール結果を選んだモデル提供元へ送る
  ときだけ端末を出ます。これは他のメッセージと同じ経路です。
- **端末に残るもの。** ワークスペース、変更前のスナップショット、操作ログ、記憶した事実、スキル
  ファイルは端末上に残ります。操作ログにはツール名、引数（300 文字に短縮）、結果が入り、暗号化して
  保存され、同じ設定画面からいつでも消去できます。

## 6. バックアップ

バックアップはあなたが作成する単一の `.lcb` ファイルです。ノート、タスク、バージョン履歴、ノートブック、会話、添付ファイル、設定、API キーを含めることができ、任意で読み込んだフォントとローカルモデルのファイルも含められます。どれを含めるか、どこへ書き出すかはあなたが選びます。

`.lcb` ファイルはすべて暗号化されます。方式は二つです。

- **パスワードなし。** アプリ内蔵の鍵で暗号化されます。Lucent とこのファイルさえあればどの端末でも復元できるので便利ですが、ファイルとアプリのコピーの両方を手にした人は誰でも読めるということでもあります。
- **パスワードあり。** 鍵はあなたのパスワードから PBKDF2-HMAC-SHA256 を 210,000 回反復して導出され、それ以外のどこにも存在しません。より強固ですが、代償はいつもどおりです。復元には同じパスワードが必要で、どこにも保存されず、忘れたパスワードは開発者を含め誰も復元できません。

パスワード保護されたバックアップには、後からパスワードを思い出せるように秘密の質問と答えを任意で添えられます。このオプションは既定ではオフで、バックアップの強度はパスワードと答えの弱いほうに合わせられます。答えを自分以外が知らない質問を選んでください。

自動バックアップを有効にすると、あなたが選んだフォルダーへ書き出し、設定した数だけコピーを保持し、構成済みの WebDAV フォルダーへもアップロードできます。どの場合もバックアップファイルは同じ暗号化コンテナです。バックアップをどこに置き、何部残すかは完全にあなたの判断であり、削除も同様です。

## 7. 端末連携

Lucent の特権シェル連携は任意で、既定ではオフであり、Lucent の外にあるソフトウェアと許可を必要とします。

Android では、Shizuku をインストールし、そのサービスを起動し、システム上で Lucent に権限を付与した場合に、アプリは Shizuku を通じて特権操作を実行できます。これは、通常のアプリだけでは実行できない操作のうち、あなたが明示的に求めたものを実行するために存在します。たとえば、あなたがダウンロードしたアプリ更新のインストールです。Lucent が Shizuku を起動することはできず、自分で権限を付与することもできず、連携を有効にして権限を付与しない限りこの経路で何かを行うこともありません。権限は Shizuku または Android の設定でいつでも取り消せ、Lucent 側でも連携をオフにできます。実際に得られた権限の uid はアプリ内に表示され、どのような身分を得ているかを確認できます。

Lucent は、必要とする通常の Android 権限も宣言しています。それぞれに目的があり、第 8 節にまとめています。

## 8. Lucent が要求する権限

| 権限 | Lucent が求める理由 |
|---|---|
| ネットワークアクセス（Android `INTERNET`） | 設定したアシスタントのプロバイダーへのメッセージ送信、オンにしたときのウェブ検索、オンにしたときの WebDAV バックアップ、オンにしたときの更新確認。これらのいずれも有効でないときは何も送信されません。 |
| 通知（Android `POST_NOTIFICATIONS`） | タスクのリマインダーの表示、および開始したダウンロード、バックアップ、生成処理の進捗表示。 |
| 正確なアラーム（Android `SCHEDULE_EXACT_ALARM`） | タスクのリマインダーを、おおよその時刻ではなく設定した時刻に発火させるため。 |
| 起動時の実行（Android `RECEIVE_BOOT_COMPLETED`） | 端末の再起動後にリマインダーを再登録し、翌日のリマインダーが再起動を越えて残るようにするため。 |
| フォアグラウンドサービス（Android `FOREGROUND_SERVICE`、`FOREGROUND_SERVICE_DATA_SYNC`） | アプリが前面にない間もバックアップ、ダウンロード、モデル生成を続行し、途中で終了されないようにするため。 |
| 生体認証による解除（Android `USE_BIOMETRIC`、Windows では Windows Hello） | アプリロックのパスワードを入力する代わりに、指紋や顔でアプリを解除するため。任意で既定はオフ、ローカルの解除にのみ使われます。 |
| 振動（Android `VIBRATE`） | 入力時の触覚と触覚フィードバック。 |
| パッケージのインストール（Android `REQUEST_INSTALL_PACKAGES`） | あなたがダウンロードを選んだ更新を、システムのインストーラーでインストールするため。 |
| Shizuku サービス権限（Android `moe.shizuku.manager.permission.API_V23`） | 第 7 節で述べた任意の特権連携。Shizuku をそもそも利用できるようにするために宣言しているだけで、あなたが Shizuku をインストールして許可しない限り効果はありません。 |

Lucent はファイルやストレージへの広範なアクセス権を要求しません。ファイルとフォルダーはあなたがシステム標準のピッカーで選び、Lucent は選ばれた項目だけを受け取ります。フォントとモデルファイルも同じで、あなたが選び、アプリ専用の保存領域へコピーされます。

## 9. あなたが握る制御

Lucent のプライバシーは一連のスイッチであり、そのすべてがあなたの手元、つまり設定の中にあります。主なものは次のとおりです。

- **アプリロック。** 設定 → セキュリティ。パスワードを設定し、必要なら忘れたときのための秘密の質問も設定します。保存されるのはソルト付きハッシュだけです。
- **解除試行回数の上限。** アプリロックと同じ画面。最初のラウンドと以降のラウンドで許される試行回数を設定します。失敗すると段階的に延びる待機時間が発生し、再起動をまたいで保持されます。
- **繰り返し失敗後の消去。** 同じくアプリロックの画面にあり、既定はオフ。設定した回数だけパスワードを間違えると、すべてが消去されます。これは永久的で、誰にも元に戻せません。
- **生体認証による解除。** 任意で、既定はオフ。
- **ブラックアウトモード。** 設定 → プライバシー。オンにしている間は何も端末の外へ出ません。クラウドアシスタント、ウェブ検索、ネットワーク機能が遮断され、クラウド関連の画面は凍結され、アプリは最近使用したアプリ一覧から隠れてスクリーンショットも撮れなくなり、共有先からも外れ、戻るたびにパスワードが必要になります。他のあらゆる設定より優先され、オフにすると以前の設定に戻ります。
- **診断ログ。** 設定 → プライバシー。既定はオフで、明示的な同意が必要です。ローカルに書き込むだけで、アシスタントに入力したテキストを含むことがあり、あなたがエクスポートでき、いつでも消去してオフにできます。クラッシュシールドを有効にすると、捕捉したエラーが記録されるようオンに固定されます。
- **クラッシュシールド。** 設定 → プライバシー。既定はオフ。アプリ内部のエラーを捕捉して、アプリが閉じずに開いたままになるようにし、その内容をローカルに記録します。捕捉できないものも明記しています。オンデバイスモデルエンジン内部のクラッシュ、メモリ確保のためにシステムがアプリを終了する場合、応答なしとしてシステムがアプリを終了する場合です。
- **システム連携。** 設定 → プライバシー。既定はオフ。Lucent が他のアプリの共有シートに現れてよいかを制御します。
- **バージョン履歴。** 設定 → プライバシー。ノートの履歴とタスクの履歴はそれぞれオフにでき、オフにすると新しいスナップショットは保持されません。
- **アシスタントのプロバイダーとメモリ。** 設定 → アシスタント、さらにクラウドモデルまたはローカルモデル。プロバイダーを選ぶか、ネットワークを一切使わないローカルモデルを読み込んで使います。メモリ設定はモデルごとに別々で、各リクエストに含める過去の会話の量を決めます。低くすれば端末の外へ出るテキストは少なくなります。
- **ウェブ検索。** 設定 → アシスタント → パーソナライズ。スイッチは一つで既定はオフ、隣で検索エンジンを選びます。ローカルモデルをエージェントモードなしで使っている間は、使うものが何もないため隠れ、あとで元のまま戻ります。
- **セマンティック検索。** 設定 → アシスタント。使用中のモデルに従います。ローカルモデルなら索引は端末内、クラウドモデルならテキストはプロバイダーへ送られます。モデルを切り替えれば動作も変わり、アシスタントを使わなければ何も起きません。
- **バックアップの内容とパスワード。** 設定 → データ。バックアップに含めるものと、パスワードで保護するかどうかを選びます。自動バックアップ、そのフォルダー、間隔、保持する部数はすべてあなたが設定するもので、既定はオフです。
- **クラウドバックアップ。** 設定 → データ。既定はオフ。WebDAV の資格情報はいつでも入力・消去できます。
- **暗号化チェック。** 設定 → セキュリティ。保存された値が封印され正しく開けることを、必要に応じて確認します。
- **すべてのデータを消去。** 設定 → データ。第 10 節をご覧ください。

## 10. 保持と削除

Lucent はあなたが削除するまでデータを端末内に保持します。削除したノートとタスクはまずゴミ箱に入り、ゴミ箱を早く空にするかすべてのデータを消去しない限り、30 日後に完全に削除されます。バージョン履歴は対応する履歴設定がオンの間だけ保持され、属するノートやタスクと一緒に削除されます。

すべてを削除するには：

- **設定 → データ → すべてのデータを消去** は、すべてのノート、タスク、会話を削除し、添付ファイルを除去し、履歴を消し、API キーを含む設定を初期値に戻し、読み込んだモデルとフォントを削除し、ローカルの診断ログを消去してログをオフにし、アプリのキャッシュを空にします。元に戻せません。ノートだけ、タスクだけ、チャット履歴だけを消去する個別の操作もあります。
- Android または Windows のシステム設定で**アプリのデータを消去**すると、同じようにアプリの保存領域が削除されます。
- **Lucent をアンインストール**すると、アプリとそのプライベート領域が削除されます。

Lucent の手の届かないものが三つあり、アプリが代わりに削除することはできません。

- フォルダー、別の端末、クラウドサービスへエクスポートしたバックアップファイル
- すでに WebDAV サービスへアップロードされたバックアップ
- アシスタントを通じて AI プロバイダーへ送った内容、または検索サービスへ送った内容。これらにはそのプロバイダー自身の保持方針が適用されます。

これらも消したい場合は、ファイルを削除し、プロバイダーが用意する削除機能を使ってください。

## 11. 子どもについて

Lucent は汎用的なノートおよびタスク管理アプリです。子ども向けではなく、アカウントの仕組みも広告もソーシャル機能もありません。開発者は子どもを含め誰からも個人情報を収集しません。アプリのデータは、それを使っている人の端末内に留まります。

## 12. 本ポリシーの変更

将来のバージョンの Lucent でデータの扱いが変わる場合、本ポリシーは更新され、冒頭の日付も変わります。実質的な変更、つまり端末の外へ出るデータに影響する変更は、それを導入するバージョンのリリースノートに記載します。あなたに適用されるのは、お使いの Lucent に同梱された版の本ポリシーであり、その履歴はリポジトリのコミット履歴で確認できます。

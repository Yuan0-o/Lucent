# 𝓛𝓾𝓬𝓮𝓷𝓽

### 现代 · 极简 · 低调得有点过分

**一款笔记与任务管理应用，配一个真正能碰你数据的助手——所有内容封存在你设备上的加密数据库里，通晓四种语言，全程在 GitHub 上按一个按钮就能构建完成。它有口袋版和桌面版两种尺寸——Android APK 和 Windows 安装包——共享同一颗心脏，随时准备走得更远。**

## 总体思路

市面上大多数笔记应用，让你从三个选项里痛苦地选两个：好看的、私密的、或者聪明的。你挑两个，然后忍受剩下的那个遗憾。Lucent 可不吃这套。你写的所有内容都封存在一个加密数据库里，永远不会离开你的设备。助手可以是你付费的云端模型，可以是运行在你眼前这台机器上的本地模型，也可以干脆不存在。而且，它的构建不需要你本地装任何工具：在 GitHub 上按一个按钮，去泡杯茶，回来时一个 APK 或 Windows 安装包就已经在等着你了。

## 一个应用，放哪儿都行

Lucent 是**一件产品，一颗共享心脏**：铁律就是——每个功能都会登录它发布的所有平台。口袋和桌面，说的是同一种语言：

- **`:app`** —— Android 应用（Kotlin + Jetpack Compose，Room + SQLCipher，通过 NDK 调用 llama.cpp）。由 `.github/workflows/build.yml` 构建为签名的 Release APK。
- **`:desktop`** —— 桌面应用，目前是 Windows（Compose for Desktop，纯 JVM，JDBC 调用 SQLite，llama.cpp 编译为 DLL）。由 `.github/workflows/build-windows.yml` 构建为双击即装的 `.exe` 安装包。
- **`:shared`** —— 两个平台共同编译的同一个源码树：业务逻辑、数据、大部分界面、一份四种语言的翻译目录。改一次，两台机器都变。

所有能共享的都待在 `shared/` 里；那些实在没法共享的——`SettingsRepository`、`Daos`/`Db`、`DocumentExport` 以及最大的几个界面——每个平台各留一份，因为它们的边界嵌得太深。每个原生构建阶段都是可选的，所以某个环节出问题时，你得到的是一份能用的应用，而不是一个等待室。

## 有手（而不只是有意见）的助手

这是 Lucent 定义性的功能。自带模型——OpenAI、Anthropic 和 Google 的请求格式它都说得流利，可以保存多个配置，一键切换——或者直接在设备上跑全套。什么都不配，助手就不存在；笔记应用本身毫不逊色。

让它值得拥有的，是它能*动手*：创建、读取、编辑、标色、置顶、归档、删除笔记；创建、完成、重开、排期、优先级排序任务；用真正的过滤语言搜索；以及附加、重命名或删除文件。在改动任何东西之前，它会精确地向你展示它打算做什么——用你的语言，在一个本身就是编辑器的对话框里，每一个有争议的字段在你确认之前都可编辑。你的回答永远是最终裁决。一个有意见但没有手的东西叫聊天；这是一个被告知要先敲门的管家。

对话想聊多久聊多久，随你一起走；模型的推理过程可以显示为可折叠的轨迹，每行对应一次工具调用。

## 记得自己曾经的笔记

每一次有意义的编辑都会被快照，所以你能精确地看到某个笔记之前写了什么，并在某次自信的重写被证明是过度乐观时，把它恢复回来。输入 `[[购物清单]]`，它就变成一个可点击的链接；指向一个还不存在的标题时，链接会变红，直到你点击它，笔记便礼貌地应声而生。Markdown 在你想要的时候渲染，在你不需要的时候保持原样。复选框是头等公民：原地修改条目，当一个小条目突然有了大抱负时，打开一个宽敞的弹出编辑器。标签、颜色、置顶、单独加密的附件、富文本、一个给那些文字无法触及的想法准备的涂鸦画布，以及一个自带独立锁的私密区域——还有垃圾桶旁的草稿，所以一个未完成的想法永远不会是一个被抛弃的想法。

一张空白笔记提供四个一键模板——日记、会议、项目创意、清单——然后真正的妙招来了：你自己的模板。保存一个，它会在你今后每一次打开空白页时迎接你；长按可以编辑或淘汰任意一个模板，内置的也不例外。

## 真正有意义的截止日期

子任务、优先级、重复周期、以及重启后依然坚挺的提醒。截止日期从自然语言解析——*下周五6点* 变成一个真正的时间戳和一个真正的闹钟——重复节奏是一等公民，而不是一句最终会放弃的聪明话。完成一个任务，它连带整个复选框一起勾掉，已完成的任务会自动前往一个属于它们自己的屏幕。

## 或者，直接在设备上跑全套

导入一个 `.gguf` 文件（或者一个里面装着 `.gguf` 的 `.zip`），助手就会通过直接在设备上运行的 llama.cpp 来回答——无账号、无 API 密钥、无网络，你离开应用的瞬间模型就被卸载。大约 1–4 GB 的 Q4 模型在手机上刚刚好；桌面端可以更大胆一些。工具函数在本地是可选加入的，GPU 加速是在一条直白的警告之后再做的选择：CPU 永远能工作，而 GPU 如果意见不合，会优雅地降级。视觉也是可选的——导入一个 mmproj 文件，助手就能看一张照片，然后像一个略微有预知能力的图书管理员一样讨论它。

## 四种语言，无缝切换

英语、简体中文、日本語、한국어——每个屏幕、对话框、日期格式和模板。切换语言，整个应用在同一帧内随之改变，因为只有一份目录，界面读取的就是它：每个词只存一次，这是架构的必然，而非细心的结果。

## 它的样子：坦坦荡荡，玻璃质感

一个流动的渐变在毛玻璃面板后方漂移，模糊着它下方经过的一切，几乎从不重复，以设备事先同意的代价运行。八个风格系列，丰富到有些奢靡的调色板，还有一个自动循环或随机的陪伴功能，悠然穿梭其间。浅色、深色、跟随系统，以及一系列 Monet 色调的主题——在 Android 12 及以上，调色板会借用你壁纸当天的配色方案。小部件把同样的玻璃质感带到你的启动器上；在 Windows 上，应用滑入系统托盘，侧边栏取代底部的标签栏——因为一台大屏幕显示器理应得到比手机布局横向拉伸更好的待遇。

## 算数的锁，和你一起走的备份

应用锁是一条真正的暴力破解防御策略，而非一句礼貌的请求：递增的冷却时间、重启后依然存在的计数器、一个可选的安全问题、一个可选的自动销毁功能，以及一个在冷却期间礼貌地"不在办公室"的指纹（Android）或 Windows Hello（Windows）选项。数据库静态加密，附件独立加密，备份是一个受密码保护的 `.lcb` 文件，携带笔记、任务、历史、聊天、附件和设置跨设备流转——在改动任何一条数据之前先预览，并且可以设置为自动运行。一个谁也读不了的备份叫纪念品，不叫备份——所以这个备份在导出时能读，在导入时也能读。

## 结构性隐私，而非仅仅承诺

在你自己主动导出或给模型一个查看的理由之前，没有任何东西离开设备。分享面板集成默认关闭；诊断信息默认关闭且保留在本地；你连接的助手服务完全由你选择；云同步是一个你自行配置的模块，通过 WebDAV。加密唯一有意的例外——导出为 Markdown、Word、PDF 或 Excel——正是为了你能在其他任何地方打开这些文件，这恰恰是它的意义所在。

## Rust，但只在它值得的地方

两个热点路径用 Rust 编写，通过 JNI 调用——备份和附件加密背后的 PBKDF2 和 AES-256-GCM 例程，以及流动背景背后的数学运算。两者都在原生库不可用时回退到功能完全相同的 Kotlin 实现，所以应用永远不会被编译器绑架。

## 构建它（没错，穿着睡衣在手机上就能搞）

不需要 Android Studio，不需要本地 SDK，不需要命令行。推送到 GitHub，打开 **Actions**，运行你想要的 workflow，下载结果——一个正确签名的 Release APK，或一个双击即装的安装包。Workflow 文件就存放在仓库里，所以配方就在盒子里，而不是在作者的脑子里；构建过程和代码一样可审查。

## 项目结构

```
shared/       这——就是——那个——唯一的共享源码树。业务逻辑和大部分界面在这里只写一次，
              :app 和 :desktop 都编译它。改一个文件，两个平台一起变。
app/          Android 模块 (:app) — Activity 壳、Room 数据库层、JNI 桥、小部件，
              以及其他真正绑定 Android 的代码
desktop/      桌面模块 (:desktop) — Compose for Desktop 壳、android.* 的 JVM 垫片、
              JDBC 数据库核心、引擎 DLL 的原生 CMake 构建
rust/         Rust 加速器（跨平台共享）
.github/      build.yml（Android APK）、build-windows.yml（Windows 安装包）、check.yml
```

## 它下一步要去哪

Lucent 对于一张待办清单来说，是一大坨应用，而且它从未为此道过歉。有记忆的笔记、有牙齿的任务、有手有礼貌的助手、信守承诺的加密、值得一看的界面。用一周试试，看看你注意到什么；用一个月试试，然后你会发现——你已经不再注意到它了。

## だいたいこんな感じ

世のメモアプリのほとんどは「見た目が良い」「プライベート」「賢い」の三つから二つ選べ、というスポーツを強いてきます。二つ選んで、残りの一つにがっかりする。Lucent はその取り決めを丁重に辞退します。あなたが書くものは全て暗号化データベースに封印され、デバイスの外には絶対に出て行きません。アシスタントは、お金を払って使うクラウドモデルにも、目の前のマシンで動くローカルモデルにも、あるいは一切なしにもできます。そして、ローカルに開発ツールを一切入れずともビルド可能：GitHub でボタンを押して、コーヒーを淹れに行って戻ってくれば、APK か Windows インストーラーが出来上がっています。

## ひとつのアプリ、どこにでも

Lucent は **ひとつの製品にひとつの共有された心臓** を持っています。基本ルールは「出荷する全てのプラットフォームに全ての機能が載る」です。あなたのポケットと机の上は同じ言葉を話します：

- **`:app`** — Android アプリケーション（Kotlin + Jetpack Compose、Room on SQLCipher、llama.cpp を NDK 経由で）。`.github/workflows/build.yml` が署名済みリリース APK をビルドします。
- **`:desktop`** — デスクトップアプリケーション（現時点では Windows。Compose for Desktop、純正 JVM、JDBC 経由の SQLite、llama.cpp は DLL としてコンパイル）。`.github/workflows/build-windows.yml` がダブルクリックで動く `.exe` インストーラーをビルドします。
- **`:shared`** — 両方のプラットフォームがコンパイルする単一のソースツリー。ビジネスロジック、データ、ほとんどの UI、四ヶ国語対応の翻訳カタログがここに。一度編集すれば、両方のマシンが変わります。

共有できるものは全て `shared/` に住んでいます。`SettingsRepository`、`Daos`/`Db`、`DocumentExport`、そして大きな画面など、共有できない少数のものだけがプラットフォームごとに別々に存在します——それらの継ぎ目は深いからです。ネイティブビルドの各段階はそれぞれオプションなので、どこかでトラブルがあっても、ただの待合室ではなく動くアプリが手に入ります。

## 単なる意見ではなく、実働するアシスタント

これこそが Lucent を定義する機能です。自分のモデルを持ち込んでください——OpenAI、Anthropic、Google のリクエスト形式を流暢に話し、複数のプロファイルを保存してワンタップで切り替えられます——あるいは、すべてをデバイス上で動作させることもできます。何も設定しなければアシスタントは存在せず、メモアプリとしては何も欠けていません。

このアシスタントを導入する価値は、それが **実際に行動できる** ことにあります：メモの作成、読み取り、編集、色付け、ピン留め、アーカイブ、削除。タスクの作成、完了、再開、スケジュール、優先順位付け。本物のフィルター言語を使った検索。ファイルの添付、リネーム、削除。何かを変更する前に、アシスタントは自分が何をしようとしているかを正確に表示します——あなたの言語で、それ自体がエディターになっているダイアログの中で、1バイトも書き込まれる前にすべての議論可能なフィールドを編集できます。あなたの返事が常に最終決定です。意見はあるけれど手がない相手とはチャットをするだけです；これは、ノックしてから入るように言われている執事なのです。

会話は好きなだけ続けられ、あなたと一緒に旅をします。モデルの推論過程は折りたたみ可能なトレースとして表示され、ツール呼び出しごとに一行ずつ表示されます。

## 過去の自分を覚えているメモ

意味のある編集はすべてスナップショットされます。つまり、メモが以前に何と書かれていたかを正確に読めますし、自信満々の書き直しが実は単なる楽観主義だったときに復元もできます。`[[買い物リスト]]` と入力すれば、それはタップ可能なリンクになります。まだ存在しないタイトルを指していると、リンクは赤く光ります——タップすると丁寧にそのメモが生成されます。Markdown は見たいときにレンダリングされ、見たくないときは入力されたままを保ちます。チェックリストは第一級市民です：その場で項目を言い換えたり、簡単な項目が野心的になったときには広々としたポップアウトエディターを開いたり。タグ、色、ピン留め、個別に暗号化された添付ファイル、リッチテキスト、言葉が届かない思考のための doodle キャンバス、そして独自のロックを持つプライベートエリア——ごみ箱の隣には下書きもあり、未完成の思考が決して放棄されたものになりません。

白紙のメモは、ジャーナル、ミーティング、プロジェクト案、チェックリストの4つのワンタップスターターを提供します——そして本当のトリックは、自分だけのテンプレートです。テンプレートを保存すれば、次に白紙のページを開くたびに出迎えてくれます。長押しでテンプレート（組み込みのものも含む）を編集したり引退させたりできます。

## 本当に意味のある期限を持つタスク

サブタスク、優先順位、繰り返しスケジュール、そして再起動後も生き残るリマインダー。期限は自然言語から解析されます——*来週の金曜日の6時に* は本物のタイムスタンプと本物のアラームになります。繰り返し周期は第一級の機能であり、いつか諦める巧妙な文章ではありません。タスクを完了すると、そのチェックリスト全体も一緒にチェックされ、完了したタスクは専用の画面に移動します。

## 全部デバイス上で動かすことも

`.gguf` ファイル（またはそれを含む `.zip`）をインポートすれば、アシスタントはデバイス上で直接動作する llama.cpp を使って応答します——アカウントもAPIキーもネットワークも不要で、アプリを離れた瞬間にモデルはアンロードされます。スマートフォンではだいたい 1〜4 GB の Q4 モデルがちょうど良いところです。デスクトップならもう少し楽観的になれます。ツールはローカルではオプトイン制で、GPU アクセラレーションはあらかじめ警告を表示した上で選択します：CPU は常に動作しますし、GPU が合わなければ優雅にフォールバックします。ビジョンもオプションです——mmproj ファイルをインポートすれば、アシスタントは写真を見て、ちょっとだけ千里眼を持った司書のように語ってくれます。

## 四ヶ国語、儀式なしで切り替え

英語、中文、日本語、한국어——すべての画面、ダイアログ、日付フォーマット、テンプレート。言語を切り替えれば、アプリ全体が同じフレームで追従します。ひとつのカタログがあり、インターフェースはそれを読んでいるからです：各単語は、注意深さではなく設計によって一度だけ保持されています。

## 見た目：恥じることなく、ガラスでできている

生きているグラデーションが、曇りガラスのパネルの背後を漂い、その下を通るものをぼかしながら、決して完全には同じパターンを繰り返さず、デバイスがあらかじめ承諾したコストで動作します。8つのスタイルファミリーにわたる豊富なパレット、自動巡回またはランダムなコンパニオンがゆったりとパレットを巡ります。ライト、ダーク、システム、そして Monet 調のテーマのギャラリー——Android 12 以降では、パレットがあなたの壁紙の今日の予定を借りてきます。ウィジェットは同じガラス質の表面をランチャーにもたらします。Windows では、アプリはトレイに格納され、サイドバーが下部タブバーに取って代わります——大きなモニターが、引き伸ばされたスマホのレイアウトより良いものに値するからです。

## 本気のロックと、あなたと共に去るバックアップ

アプリロックは、丁寧なお願いではなく、本物のブルートフォース対策ポリシーです：エスカレーションするクールダウン、再起動後も持続するカウンター、オプションのセキュリティ質問、オプションの自己破壊機能、そしてクールダウン中は丁寧に「不在」の状態になる指紋認証（Android）または Windows Hello（Windows）。データベースは保存時に暗号化され、添付ファイルは個別に暗号化され、バックアップは単一のパスワード保護可能な `.lcb` ファイルとして、メモ、タスク、履歴、チャット、添付ファイル、設定をデバイス間で運びます——1アイテムも変更される前にプレビューされ、自動実行も設定可能。誰にも読めないバックアップは、思い出の品であってバックアップではありません。だからこのバックアップは、出ていくときにも入ってくるときにも読まれます。

## 約束ではなく、構造としてのプライバシー

あなたがエクスポートするか、モデルに見る理由を与えるまでは、何もデバイスから出て行きません。共有シートの統合はデフォルトでオフ。診断情報はデフォルトでオフで、ローカルにのみ保存されます。接続するアシスタントサービスは完全にあなたの選択。クラウドミラーリングはあなた自身が WebDAV 経由で設定するモジュールです。暗号化の唯一の意図的な例外——Markdown、Word、PDF、Excel へのエクスポート——は、どこでも開けるファイルであり、それがそもそもの目的です。

## Rust、でも本当に必要なところだけ

2つのホットパスが Rust で書かれ、JNI 経由で呼ばれています——バックアップと添付ファイル暗号化の背後にある PBKDF2 と AES-256-GCM のルーチン、そして漂う背景の数学的処理。どちらも、ネイティブライブラリが存在しない場合は同一の Kotlin にフォールバックするので、アプリがコンパイラに人質に取られることは決してありません。

## ビルド方法（そう、パジャマ姿でスマホからでも）

Android Studio も、ローカル SDK も、コマンドラインも不要。GitHub にプッシュして、**Actions** を開き、欲しいワークフローを実行し、結果をダウンロードするだけ——適切に署名されたリリースか、ダブルクリックで動くインストーラーが手に入ります。ワークフローはリポジトリの中にあり、レシピは作者の頭の中ではなく箱の中に入っていて、ビルドはコードと同じくらい検査可能です。

## プロジェクト構成

```
shared/       ただひとつの共有ソースツリー — ビジネスロジックとほとんどの UI がここに
              ONCE 存在し、:app と :desktop の両方がコンパイルします。ここにあるファイルを
              編集すれば、両方のプラットフォームが同時に変わります。
app/          Android モジュール (:app) — Activity シェル、Room データベース層、JNI ブリッジ、
              ウィジェット、その他 Android 固有のコードのみ
desktop/      デスクトップモジュール (:desktop) — Compose for Desktop シェル、android.* の
              JVM シム、JDBC データベースコア、エンジン DLL 用ネイティブ CMake ビルド
rust/         Rust アクセラレーター（全プラットフォーム共通）
.github/      build.yml（Android APK）、build-windows.yml（Windows インストーラー）、check.yml
```

## これからどこへ行くのか

Lucent は ToDo リストにしてはかなり大掛かりなアプリケーションであり、そのことをひたすら謝ったりはしません。記憶を持つメモ、牙を持つタスク、手とマナーを持つアシスタント、約束を守る暗号化、そして見る価値のある表面。一週間使ってみて、何に気づくか確かめてみてください。一ヶ月使えば、気にしなくなったことに気づくでしょう。
